This is a fork of PavelZinchenko's game Event Horizon with some features added and game balance adjusted for better gaming experience.

The majority of the changes I made was based on @zkip's fork (https://github.com/zkip/event-horizon-main).

If you want to compile this game in unity, you may encounter compilation error: "ObscuredType unknown" if you do not have ATCk in your unity assets. To solve this issue, run UpdateSubmodules.sh before you compile. For more info regarding this issue, see: https://github.com/PavelZinchenko/event-horizon-main/issues/325#issuecomment-2043104776.
